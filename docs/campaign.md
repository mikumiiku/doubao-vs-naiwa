# 十关冒险

每关加入一张豆包卡。第1、3、5、7、9关依次登场普通奶蛙、大笑奶蛙、奶蛋、奶鸡和吼啦奶蛙；通关前一关获得下一关的新卡。第五关的卡在随后普通战斗中使用。

## 奶蛋入侵

奶蛋入侵持续180秒，共649只蛋。固定150BPM节奏以单拍、双连、上下跳点和终段连打逐渐加压，约49—57秒和103—111秒有两段缓冲，125秒后约每秒五次点击。重试时谱面、弹跳参数和行序一致。速度从424.5像素/秒升至680像素/秒，按目标到达时刻生成，速度变化不会打乱出场次序。

奶蛋中心和点击位置必须同时位于从左往右第三列，鼠标还须命中蛋中心半径34像素的小圆圈。外圈提前0.85秒出现并收拢；相对到达列中心时刻，前后各90毫秒可击碎，前后各35毫秒判为“精准”，其余有效命中判为“命中”。编号提示顺序，第三列持续金框标记。可用鼠标点击，或鼠标瞄准后按Z/X；长按自动重复无效，一次输入至多击碎一只。该节奏由关卡自己的计时驱动，没有声称与现有背景音乐逐拍同步。

精准与普通命中分别计300和100基础分，连击提高得分倍率。超出命中窗口即记漏蛋并断连击；允许漏四只，第五次漏蛋失败。场上清空后仍等180秒结束才结算。此关不种豆包，不收面团，也不使用大肥鱼。设计参考[osu!官方玩法](https://osu.ppy.sh/wiki/en/Game_mode/osu%21)的提示圈、瞄准、时机判定和连击；[官方难度说明](https://osu.ppy.sh/wiki/en/Beatmap/Overall_difficulty)用于核对命中窗口概念。

入场由豆包的四段对话介绍玩法，使用招呼、讲解、眨眼握拳三种立绘。上一句和下一句支持鼠标与键盘，最后点“开打！”开始三分钟计时。上方只有成绩、倒计时和当前节奏段落，没有规则横幅。“和豆包聊聊”可以重看对话，重看期间奶蛋和时间冻结。对话中按Esc进入暂停，继续后回到原句。新存档保留谱面位置、分数和对话页码；旧短版第五关存档从新谱面起点暂停进入，正式解锁进度保留。

常规战斗里的奶蛋从第7关起出现：沿移动距离连续旋转，越过第一只豆包后落地孵成奶鸡。第5关只打蛋，第6关没有会孵鸡的奶蛋，奶鸡因此不会提前登场。

## 传送带

点传送带上的卡，再点空格种下，无面团消耗和种植冷却。点到被占用的格子保留原卡，取消选择也不丢卡。最多积存八张，满带暂停供卡；供卡循环包含全部十种豆包，持续穿插射手。和面豆包与糖包产生的补给变为加送卡，满带时补给保留。

## 波次与难度

普通关从单行、三行、四行过渡到五行；起始面团从50逐步增加至200，第9关为250。天降面团每12秒一团，经济单位承担中后期补给。

普通战斗第一波只来普通奶蛙，新精英从第二波登场。之后逐波提高精英权重，出怪间隔与波间等待逐关缩短；同关后几波的数量也会增加。后续波次按上一波全部出场的时间推进，场上残存奶蛙不会阻塞新波。出生行对当前拥挤程度做加权，避免完全随机导致同一行过度扎堆。大笑奶蛙保持较低权重和自然出场数量限制。

常规关总数依次为9、14、19、24、30、34、38、40，第10关48只。第五关独立为649只点击目标。

关卡类型规则已集中到 `levelKind`：第5、15、25等关使用小游戏类型，第10、20、30等关使用传送带类型。目前可玩的内容是第1—10关，后续关卡尚未加入关卡表。

## 入口与存档

首页进入冒险模式，正式进度逐关解锁。`/debug` → 冒险模式可以直接选择全部十关，调试战斗不读写正式进度。普通战斗、奶蛋入侵和传送带都支持暂停与正式存档；读取后先暂停。旧版战斗存档会从对应关卡重新开局，已经解锁的关卡保留，旧蒜香卡迁移为糖包。
