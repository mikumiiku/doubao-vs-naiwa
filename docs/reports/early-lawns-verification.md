# 早期草坪与豆包对话验证

第一关只开放中间一行，第二、三关开放中间三行，第四关开放前四行。未开放区域使用裸土地景，没有行内文字、灰色遮罩、种植预览或推车。草坪注册到既有网格，周围房屋与花园边界保持原图。
