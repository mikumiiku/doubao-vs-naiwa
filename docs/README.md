## 交互预览

开发服务器启动后打开以下页面。它们直接使用正式源码和完整运行素材，不读写正式解锁进度。

| 页面 | 用途 |
| --- | --- |
| [十关演练](previews/campaign-preview.html) | 任意关卡、全部角色、窄屏与单步检查 |
| [战斗机制](previews/combat-preview.html) | 推搡、感染、奶蛋滚动、跳跃与孵化 |
| [普通奶蛙步态](previews/ordinary-walk-preview.html) | 左右腿反相和完整步态循环 |
| [大笑奶蛙动作](previews/frog-animation-preview.html) | 正常、断手、感染与倒地 |
| [失败演出](previews/lose-animation-preview.html) | 咀嚼动画、音效和失败按钮 |
| [豆包对话](previews/egg-dialogue-preview.html) | 奶蛋入侵开场、立绘差分与420像素排版 |
| [奶蛋节奏](previews/egg-rhythm-preview.html) | 热身与终段、50毫秒单步、命中与漏蛋检查 |
| [不知火蛙](previews/shiranui-preview.html) | 完整步态、挥扇滑步、风刃削弱、啃咬、倒地及音效 |

当前画面证据位于 `screenshots/`，校验输出位于 `reports/`，历史中间稿位于 [archive](archive/README.md)。正式调试入口为 `/debug`。
